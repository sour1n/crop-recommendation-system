About Project

This application analyzes soil composition (N, P, K ratios) alongside local climatic metrics (temperature, humidity, pH, and rainfall) to recommend the most suitable crop for cultivation[cite: 1].

  • Dataset: Includes multi-attribute environmental data across multiple crop species (`Crop1.csv`)[cite: 1].
  • Model Training: Evaluated using Python machine learning models within Jupyter/Google Colab notebooks.
