About Project

This application analyzes soil composition (N, P, K ratios) alongside local climatic metrics to recommend the most suitable crop for cultivation.

  • Dataset: Includes multi-attribute environmental data across multiple crop species (Crop1.csv).
  • Model Inference: Powered client-side using ONNX Runtime Web.
